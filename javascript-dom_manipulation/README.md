# JavaScript - DOM Manipulation

## Description
Ce projet contient des exercices JavaScript pour apprendre à manipuler le DOM (Document Object Model) avec JavaScript vanilla.

## Objectifs pédagogiques
- Utiliser `document.querySelector()` pour sélectionner des éléments HTML
- Modifier les styles CSS via JavaScript
- Comprendre les concepts fondamentaux du DOM manipulation
- Écrire du code JavaScript semistandard compliant

## Fichiers du projet

### 0-script.js
Script qui change la couleur du texte de l'élément `<header>` en rouge (#FF0000) en utilisant `document.querySelector()`.

**Utilisation:** Incluez ce script dans un fichier HTML contenant un élément `<header>`.

## Requirements
- Navigateur Chrome version 57.0 ou ultérieure
- Aucune utilisation de `var` (utiliser `const` ou `let`)
- Code conforme aux standards semistandard JavaScript
- Les fichiers doivent se terminer par une nouvelle ligne
- Pas de rechargement de la page pour les manipulations du DOM
